# Scientific Python Assistant 🚀

تطبيق ويب تعليمي متكامل تم بناؤه باستخدام **Python** و **Flask**، يهدف إلى مساعدة الطلاب في حل المسائل الفيزيائية والرياضية مع ميزة البحث العلمي عبر الـ API.

## ✨ المميزات (Features)
- **قسم الفيزياء:** حساب الوزن ($P = m \times g$) مع عرض خطوات الحل بالتفصيل.
- **قسم الرياضيات:** تحويل الأعداد من النظام العشري إلى النظام الثنائي (Binary Conversion).
- **البحث العلمي (API):** الاتصال بـ **Free Dictionary API** لجلب تعريفات دقيقة للمصطلحات العلمية باللغة الإنجليزية.
- **واجهة عصرية:** تصميم متجاوب (Responsive) باستخدام **HTML5** و **CSS3**.

## 🛠️ التقنيات المستخدمة (Technologies)
- **Backend:** Python 3.x, Flask
- **Frontend:** HTML5, CSS3
- **Networking:** Requests Library (للاتصال بالـ API)
